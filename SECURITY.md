# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue.

Email **ankitanshu889@gmail.com** with:

- A clear description of the vulnerability
- The affected page, file, dependency, or workflow
- Steps to reproduce the issue
- Its potential impact
- A suggested fix, if available

You will receive an acknowledgement after the report is reviewed. Please allow reasonable time for investigation and remediation before disclosing the issue publicly.

Use regular [GitHub issues](https://github.com/Ankit-Anshu/stagepath/issues) for broken links, inaccurate learning content, visual defects, and other non-security problems.
