# docs/archive/

Historical working documents from earlier content-generation passes — kept for provenance, not
current documentation. If you're looking for how to contribute, start at
[CONTRIBUTING.md](../../CONTRIBUTING.md) instead; nothing in this folder is a live guide.

- **`content-note-generation-prompt.md`** — the original prompt used to drive an early batch pass that
  generated skill `note:` content (see [scripts/README.md](../../scripts/README.md)). It predates the
  "no `subtopics:` on new skills" and "no `verify:` on new skills" guidance now documented in
  [content/skills/README.md](../../content/skills/README.md) — follow that current file, not this one.
